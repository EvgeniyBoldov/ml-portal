# Корпоративный глоссарий

Глоссарий — единый каталог терминов компании. Термин не бывает глобальным,
локальным, проектным или командным: он либо утверждён и присутствует в каталоге,
либо ещё ожидает утверждения. В записи хранятся каноническое название, aliases
и общая расшифровка / определение. Скоупов и tenant-применимости у термина нет.

## Извлечение и утверждение

Документная коллекция запускает изучение документа. Извлекатель создаёт
`term` с `content.definition` и `evidence_section_ids` из документов любого
access scope. Отсутствие глобального доступа к документу не является причиной
пропустить термин. Термин без явно подтверждённой расшифровки не создаётся.

Все термины-кандидаты попадают в общую таблицу «На проверке». Пока утверждение
выполняет администратор: автоматическая публикация терминов запрещена.
Утверждение создаёт `GlossaryTerm`, отклонение требует причины. Термин открывается
в карточке термина; правила, процедуры и другие атомы — в карточке памяти.
Карточка утверждённого термина доступна по `/admin/memory/terms/:termId`.

Одинаковое нормализованное название обозначает одну запись. Повторное
подтверждение общей расшифровки добавляет aliases и обновляет ссылку на источник.
Изменение общей расшифровки требует явного решения администратора с причиной.

## Значения и применимость

Расшифровка идентифицирует термин и не задаёт конкретное значение для проекта.
Например, SLA — название понятия, а «SLA проекта A — 99,95 %» — отдельный атом
памяти со скоупом `project.a` и ссылкой на термин SLA. Для другого проекта будет
другой атом. Проектные определения, нормы, параметры, правила и процедуры
отбираются через team/project-применимость памяти, а не через варианты термина.
Ссылка на термин не подтверждает применимость атома памяти.

## Каталог и происхождение

Runtime, `memory.search`, админка и виртуальная коллекция «Глоссарий» используют
один каталог активных утверждённых терминов. Утверждённый термин сохраняется
при архивировании, новой версии или удалении документа. Ссылка на кандидат —
только происхождение; при удалении источника она обнуляется (`ON DELETE SET NULL`).
Термин деактивируется или удаляется отдельным административным действием.

Неоднозначные aliases требуют уточнения, runtime не выбирает смысл автоматически.
Чат, TurnPreflight и извлечение диалоговых фактов не создают термины.

Внутренние термины портала описаны в [Терминах разработки](DEVELOPER_TERMS.md).
